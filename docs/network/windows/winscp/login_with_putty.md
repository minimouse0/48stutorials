# 使用PuTTY登录（使用密钥登录）
## 转换私钥格式
1. 在弹出的“登录”窗口中，点击左下角的“工具”按钮。
2. 在下拉菜单中选择“在 PuTTYgen 中打开密钥”。
3. 在打开的 PuTTYgen 窗口中，点击“Load”按钮，选择你电脑上的私钥文件（如果找不到，记得在文件类型下拉框中选择“All Files (.)”）。
4. 点击确定后，如果你的私钥设置了密码，此时会提示输入密码；如果没有设置，会直接提示导入成功。
5. 点击“Save private key”按钮，将转换后的文件保存为 .ppk 格式（例如 myserver.ppk）。保存好后可以关闭 PuTTYgen 窗口。

## 在 WinSCP 中配置连接
1. 回到 WinSCP 的“登录”窗口。
2. 在右侧填写服务器信息：
    - 文件协议：选择 SFTP。
    - 主机名：填写服务器的 IP 地址。
    - 端口号：默认是 22（如果服务器改了端口，请输入修改后的端口）。
    - 用户名：填写你的登录用户名（例如 root）。
    - 密码：这里留空不填。
3. 点击下方的“高级”按钮（在密码输入框下方）。
4. 在左侧的导航树中，依次展开“SSH” -> 点击“验证”。
5. 在右侧的“密钥文件”一栏，点击后面的“...”浏览按钮。
6. 选择你在第一步中保存的 .ppk 格式私钥文件。
7. 点击“确定”返回上一个窗口。

## 保存并登录
1. 为了方便以后使用，建议点击“保存”按钮，给这个连接起个名字（比如“我的生产服务器”），并勾选“保存密码”（如果私钥有密码的话，不勾选每次登录都需要输入私钥密码）。
2. 点击“登录”按钮。
3. 第一次连接时，系统会弹出一个提示，询问是否信任该主机的密钥（提示“继续连接并添加主机密钥到缓存吗？”），点击“是”即可成功连接。
